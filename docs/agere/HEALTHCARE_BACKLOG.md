Generated by `tools/question_coverage.py` from `config/agere/healthcare_questions.json` (538 questions beyond value-based care). Counts are questions; a question can need both a new engine and missing data. Availability is checked against the read-only profiles `v1.23`, `v2.0`. VBC-library data gaps are in `docs/agere/VBC_QUESTION_COVERAGE.md`.

Existing-engine gaps found while assigning engines (not new methods): the VBC measure library lacks FUH/FUM/IET-style behavioural follow-up measures (assigned `vbc`); the knowledge base is VBC-only, so hospital-program, pharmacy and RWE explanation questions (assigned `knowledge`) need curated passages.

Found on v2.3 acceptance (2026-10-14): `discover` only takes a patient-cohort outcome, so claim-grain questions ("where are denials unexpectedly concentrated across service lines, payers and billing providers?") fail the router fill and fall to the frontier planner (~$0.41). Needed: a claim-grain outcome (denied / paid / adjusted claim line) and claim segments (service line, payer, billing provider) in `discover`.
