## Changed user behavior

- A failed presentation can trigger upstream investigation in the same request, rather than requiring an operator to start a new run. The saved original question, source identity and input membership (including an explicit empty population) govern continuation. A prior answer and machine review are not accepted as clinical truth.
- New native evidence or a newly confirmed interpretation permits another rendering. Wording changes, repeated receipts and different accounting do not. Prior artifacts, contexts and failed/unpriced usage remain inspectable. A subscription limit stops further provider work.
- Existing internal work is retained. Automatic continuation of a mixed work/monitor workflow currently requires reconciliation rather than duplicating its effects; that broader behavior is still open.
- Large native table previews now include exact repeated-category, null, missing, singleton-category and positive-number row counts computed in code. Complete original rows remain queryable. These summaries do not infer clinical status, current use or patient grain.
- Frozen artifact evidence uses the smaller of complete JSON, shared JSON and a lossless layout/shared-value encoding, with exact round-trip verification. Stable evidence precedes changing revision instructions so a repair can reuse the provider prefix. Native receipt paths and embedded data are unchanged.
