Workspace: pilot-native-v2-12, as_of 2030-05-27. Read-only. Method: derive each answer literally from `landing.sqlite` (persons via `stg_person_map`), derive it from `semantic.sqlite3` as an analyst reading `analyst_docs` would, compare, classify. Native derivations are from the delivered files, so they are independent of the semantic layer. Where I used a semantic table as a proxy (payer claim paid status, enrollment spans, labs for KED) I say so.

## Cross-cutting findings

1. **FHIR bulk `survey` Observations (PHQ-2/PHQ-9) of the 11 eCW practices never reach the semantic layer.** Native PHQ-2 FHIR rows for eCW practices (AK-0, CA-1, CA-7, CA-9, DE-0, IL-0, IN-0, KS-0, MI-0, SC-0, WA-1): 248, with 14 matching a semantic row at person level. Other practices: 635 of 635 match. For those practices, labs and vitals do arrive (they exist in eCW tables), but the survey stream has no eCW-table twin and is lost. eCW has no PHQ items of its own (`ehr_ecw_items` has no PHQ row), so the data is only in FHIR. Drives BH-02, BH-03, BH-04, BH-06, BH-13.
2. **FHIR `valueInteger` PHQ-9 values are loaded as NULL for the 4 FHIR-native practices** (CA-5, LA-0, NY-5, VA-0): 10 `measurement` rows have `value` NULL while the file has e.g. 7, 14, 16. NULL rows cannot satisfy `>= 10`. Drives BH-02 and BH-13 (4 persons).
3. **`payer_claim.discharge_date` is NULL for X12 837I inpatient claims** (348 of 1,580 bill-type-011x claims), because 837I carries `statement_to` and no discharge date. The docs do not say to use `service_to`. `admission_type` is not a modeled column at all (only in `raw_x12_837_claim`, joinable on `patient_control_number = payer_claim_id`, which the docs never state). Drives QUA-10 and QUA-11.
4. **Cross-referenced definitions** ("As CLN-15 for 2028", "as QUA-03", "QUA-10 count / ...") leave Agere without the governing rule. Agere itself says "CLN-15 governed thresholds were not available in the catalog". Drives QUA-06, QUA-14, QUA-11.
5. **"Documented diagnosis" is a three-source union** (EHR problem list, EHR encounter dx, paid payer claim dx). The semantic layer splits it across `condition`, `encounter_diagnosis`, `payer_claim_diagnosis`; Agere's runs pick different subsets. I checked the sources are faithful: native depression persons (EHR) 199 vs semantic 200; claims 492 = 492. Drives BH-02, BH-13, QUA-14.
6. **For 8 of 16 questions the semantic layer reproduces my literal derivation to within one person**, including the PDC values to 4 decimals (53.2407, 52.8384, 63.0986). The semantic layer and Agere are faithful there, so the gap to the key is not in the semantic layer's treatment of the fed streams I could check. Candidates (not testable without the keys): CCLF Part D lines not in `payer_pharmacy_claim`, PDC "best course" convention, identity, date clock. See per-question sensitivities.

## Top 3 general fixes

1. **Reconcile every native stream into the semantic layer with an automatic parity test (A and the CCLF part of D).** Compare native person/date/row counts against the modeled tables per source x year and fail the build on gaps. It would have caught: FHIR bulk surveys dropped for eCW practices, FHIR `valueInteger` read as NULL, and CCLF Part D fills not in `payer_pharmacy_claim`. Addresses BH-02, BH-03, BH-04, BH-06, BH-13, and the sensitivity on QUA-07, QUA-08, BH-12.
2. **Model the derived facts that definitions depend on instead of leaving them raw-only (A, B, C).** (a) `payer_claim.discharge_date` from statement-to for inpatient TOB, plus `admission_type` promoted to `payer_claim`, with the 837I join documented; (b) one `documented_diagnosis` view (person, icd10, source, paid flag) implementing the PL + encounter dx + paid claim union; (c) item-level questionnaire rows; (d) a doc line saying `stay` is not claims-only. Addresses QUA-10, QUA-11, BH-02, BH-13, BH-14.
3. **Make question definitions self-contained and the answer shape enforced (B).** Inline or catalog every referenced measure (CLN-15, QUA-03, QUA-10) as a governed definition (denominator, numerator, age, span, units, "last reading"), and have Agere commit to the literal reading rather than return clarify when the definition is complete; enforce `patient_set` vs `value`. Addresses QUA-06, QUA-14, QUA-11, BH-06 (run a), BH-13.
