## Decided plan (Codex review, adopted)
1. **Repair and freeze the measurement tools. Do this first, before any layer work.**
   - Scorer (generator's ecosystem/eval_questions.py ~line 1158): exact table and set comparison, empty sets correct, no
     extra-row allowance, partial credit reported separately; fixtures for extra/missing rows, empty sets, duplicate
     keys, units and malformed output. The generator owns this code; Agere supplies the failing cases.
   - Agere: fix bench/truth_run.py's table adapter (it collapses multi-column tables, ~line 66). Fix fill_events.py
     (~line 64), which merges fills of DIFFERENT ingredients in the same class (23 rows, e.g. tramadol + oxycodone):
     require the same ingredient.
   - A run manifest pins data, docs, questions, scorer version, model settings and cache policy. Costs fail closed: an
     unknown cost is never summed as $0, and cached replays are reported separately.
2. **Independent reference answers.** The generator writes them from source data. Two derivations must reconcile; Mike
   adjudicates clinical disagreements; Agere never writes keys.
3. **Pilot set:** about 100 fresh blind intents (40 template, 40 independently authored, including the clinical
   workflow tasks, and 20 ambiguous/unsupported). Dev and calibration splits, frozen before contestants run. The old
   10 held-out questions are now development evidence.
4. **One fair paid comparison:** Agere, a cheap analyst and a strong analyst on the same snapshot; 3 fresh repeats,
   replay off; every cost counted; intervals clustered by intent. Budget about $10–20; develop on $0 subagents until
   then.
5. **Hybrid core, then each layer earns its place:** a cheap model writes an analysis contract (grain, population,
   denominator, dates, perspective, exclusions); deterministic validation and compilation where supported; bounded
   SQL otherwise; clarification when meaning is unresolved. Execution checks before voting; selective escalation; no
   unanimous answer is promoted into a library or training set automatically.
6. **Abstention calibration:** 95% precision needs at least 59 independent answered cases with zero errors; 99% needs
   at least 299.
