# Evidence-supported care-option comparisons

Agere now saves an explicit comparison question against an existing patient/service review task. It brings reference-supported alternatives, reported population evidence, optional exact buyer-service proposals, declared route constraints, existing coverage/patient context and participation evidence into one inspectable result. Each alternative links back to the six current applicability questions and their prepared evidence. It does not select an intervention or rank benefit for the patient.

The initial executable comparison concerns rehabilitation delivery and uses the [official ATS guideline, Question 5](https://pmc.ncbi.nlm.nih.gov/articles/PMC10449064/), inspected October 11, 2026. The source-reported exercise-capacity contrast retains outcome, units, horizon, confidence interval, participant/trial counts, certainty and evidence-family identity. Study counts are not pooled or treated as independently reviewed trials. The arithmetic reports whether the interval contains the null; it is not an equivalence test or patient prediction. The [Medicare public coverage page](https://www.medicare.gov/coverage/pulmonary-rehabilitation-programs) is separately identified as dated background, not patient benefit verification or proof of remote-service payment.

The actual respiratory task now has one saved comparison with two alternatives and six linked unresolved questions. Its buyer declares respiratory review services, not verified rehabilitation programs, so both service proposals remain unassigned. No service was invented, no alternative ranked and no individual benefit, harm or financial estimate produced. The existing original service question and source context remain intact. Clinical, patient-goal, consent, modality, provider, benefit and capacity checks remain visible. Public-source inspection in 2026 does not establish currency at the synthetic 2029 decision date.

111 focused checks pass, including 19 new cases. They cover exact service/alternative mapping, missing inputs, modality and funding blockers, bound source context, reference/source/participation changes, immutable and concurrent saves, invalid authority fields, numerical integrity and rollback. Actual HTTP and browser entry/save verify the real comparison, question linkage, idempotency, rejection paths and unchanged work history. The initial test-fixture name collision and an invalid stale-plan fixture were corrected; no frozen core needed modification. JavaScript/Python syntax checks pass and browser errors are empty.

Preservation verifies 94 preceding identities, all program/task/event rows, three resource scenarios and 19 external research files. The continuation manifest protects 96 files. No provider/token-count calls or external actions; the ledger is unchanged and uncapped. Evidence is in `artifacts/agere-care-options-v1/`, including the implementation receipt, HTTP result, preservation result, tests and browser screenshot.

This is one machine-curated reference mapping. It is not a broad reviewed clinical recommendation engine, systematic evidence synthesis, patient-specific benefit model or approved care execution. Follow-on received-report inspection is documented separately. Broader domains, exact clinical/payer adjudication, learned quality, causal benefit, operational calibration and portable full-stack acceptance remain incomplete.
