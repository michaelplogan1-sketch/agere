# Quoted measure composition

Delivered October 10 UTC on original-cohort v1.18, entirely synthetic. The new `measure_review` operator composes four explicit roles: denominator, numerator, exclusion and attribution. It reuses the Program interpreter, pinned quoted packages and existing patient source receipts. Packages must declare the matching component role. Absent optional components remain unknown unless the caller explicitly records a descriptive omission and its reason. It does not certify an official payer measure.

The question compiler, graph planner, `/api/stack/measure`, `/measures`, main stack renderer and review assessments all use the same implementation. Full selected populations are retained. Every patient can be inspected back to each exact quote and source. Source corrections and mapping-review changes invalidate affected receipts and prevent stale work advancement. Two new quoted synthetic engineering component packages were installed; no real CMS/commercial/Medicaid definition or human review was invented.
