# Explicit evidence rechecks for successor questions

Agere now offers predecessor source selections inside each current successor reference question. The user can preview and explicitly prepare those sources again. The engine checks the exact successor link, original and new question, patient, reference version, context content and received-source contract before recording an immutable recheck receipt. No question, source selection, answer or clinical conclusion is automatically moved into replacement work.

An unchanged question can reuse the exact context only after these checks. Changed question wording creates a context for the new question. The receipt exposes exact context reuse, changes to connected source scope and any later stale dependencies. Existing bounded interpretation and authenticated packet follow-up remain available through the current question's usual controls. Rechecking sources cannot mark clinical applicability established.
