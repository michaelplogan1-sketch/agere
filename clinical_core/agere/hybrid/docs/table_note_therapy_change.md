### note_therapy_change(record_id, patient_id, event_date, encounter_id, stream, action, target, target_kind, drug_key, drug_class, reason, dictated, sound_alike_corrected, evidence_text, order_record_id, fills_after_180d, list_active_after, extractor)
Therapy decisions recorded only in note text (starts, stops, dose increases/decreases, declined therapy or services) from notes and readable outside documents, extractor therapy-rules/1 (deterministic, precision not yet measured on a held-out sample: treat as candidate evidence). target_kind = drug | drug_class | service | unspecified; drug_class from the ingredient or class word (antihypertensive, SSRI, statin). For stops: fills_after_180d = counted fills of the drug in the 180 days after the note (0 = fills ended), list_active_after = 1 when the latest medication-list entry still shows the drug active (list never updated after the stop). order_record_id = an order for a start on the same encounter/date. dictated = speech-recognition note (sound-alike drug names such as "lysine april" corrected: sound_alike_corrected = 1); clinical_note.dictated / dictation_unreviewed carry the same flags.
