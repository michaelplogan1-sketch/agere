### diagnosis_any(patient_id, icd10, source, source_detail, event_date, record_ref)
Every documented ICD-10 diagnosis of every source, one row per source record: patient_id, icd10 (upper case, as received, dotted), source = condition (EHR condition records with is_diagnosis = 1, incl. EHR problem-list conditions; assessment topics, rule-outs and laboratory-evidence rows are not diagnoses) | payer_claim (payer_claim_diagnosis of PAID payer claims, current non-duplicate versions: payer_claim.final_status = paid AND counts_in_metrics = 1) | encounter (encounter_diagnosis: EHR encounter dx and HL7 ADT DG1; the dx of payer ED claims are payer_claim rows) | problem_list (problem_list_entry), source_detail = the source table / feed, event_date (YYYY-MM-DD; claim service_from, encounter date, problem first_recorded), record_ref = source record / claim id. Use it to count or list patients with a diagnosis code: SELECT count(DISTINCT patient_id) FROM diagnosis_any WHERE icd10 LIKE 'F11%'. The same patient appears once per source record, so always count DISTINCT patient_id. condition alone holds only EHR condition records and undercounts documented diagnoses (payer claims, encounters and the problem list add patients). By library concept (no codes) use concept_patient.
