### patient(patient_id, age_reported, sex_reported, coverage_type, coverage_status, pcp_clinician_id, pcp_practice_id, birth_date, race, ethnicity, preferred_language, interpreter_needed, marital_status, zip, county, state, age_latest, data_segment, line_of_business, payer_id, coverage_source)
One row per roster patient. age_reported/sex_reported as received; coverage_type/status from latest coverage record, else (population-feed members without one) coverage_type = line_of_business of the latest enrollment month and coverage_status active | inactive by whether a span covers the as-of date; coverage_source = coverage_record | enrollment_span (NULL = no coverage received). pcp_* = latest assigned primary-care relationship.
