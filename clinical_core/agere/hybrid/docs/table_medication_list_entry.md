### medication_list_entry(patient_id, drug_key, name, rxcui, list_status, list_source, entries, first_listed, last_listed, last_fill_date, last_order_date, otc, days_since_listed, days_since_fill, discrepancy, stale, recency_weight, record_id)
Medication list per (patient, ingredient): list_status/list_source of the latest entry, last_listed, last_fill_date (paid, unreversed fills), discrepancy = listed_active_no_fill_180d (commission candidate) | filled_not_listed (omission) | listed_discontinued_still_filled, otc = 1 for over-the-counter items (list-only by nature), stale, recency_weight.
