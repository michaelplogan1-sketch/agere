### measurement(record_id, patient_id, source_table, concept, name, value, unit, value_canonical, unit_canonical, result_status, event_date, recorded_date, available_date, organization_id, loinc, loinc_source, loinc_dictionary, reference_range, abnormal_flag, event_time, component, lab_category, value_text, value_censor, excluded_reason, result_current, superseded_by_record_id, supersede_reason, local_code, interface_message_id)
Labs and vitals, one row per (record, concept); concept NULL when unmapped. value/unit as received; value_canonical in unit_canonical when the unit converts (else NULL). Cancelled results have value NULL. concept egfr = BSA-normalised eGFR only (mL/min/1.73m2 or no unit); GFR results reported in another unit (mL/min, measured GFR / clearance) are concept gfr_unnormalized and never count as eGFR. Use only result_current = 1 AND excluded_reason IS NULL rows for values; value_censor marks censored strings (eGFR ">60" -> 60 with value_censor ">"); see measurement_quality. Questionnaire totals are measurements too: mood_questionnaires rows (source_table mood_questionnaires, one row per administration, name = instrument) carry concept phq9 (PHQ-9 total 0-27) or phq2 (PHQ-2 total 0-6), value = total in points; event_time orders same-day administrations.
