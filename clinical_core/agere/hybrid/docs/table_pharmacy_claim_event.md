### pharmacy_claim_event(claim_id, source, record_id, patient_id, status, reject_code, reject_reason, event_date, drug_name, ndc, days_supply, payer_paid_delta_cents, return_to_stock, payer)
Pharmacy claim transactions from both sources (source pharmacy_claim_transactions | payer_pharmacy_claims), one row per transaction: status paid | rejected | reversed | recouped; reject_reason normalises NCPDP codes (79 = REFILL_TOO_SOON); payer_paid_delta_cents (reversal = minus the reversed claim's payment when known); return_to_stock = 1 for a payer reversal of a fill never picked up; payer = paying organization. Net pharmacy payer spend in a period = sum(payer_paid_delta_cents) by event_date. Rejections: count distinct (source, claim_id) with status rejected (refill too soon = reject_reason REFILL_TOO_SOON).
