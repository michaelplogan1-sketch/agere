### condition(record_id, patient_id, source_table, concept, label, icd10, snomed, onset, event_date, recorded_date, available_date, organization_id, icd10_source, is_diagnosis, icd10_category, chapter, chronic, normalized_label, diagnosis_basis, diagnosing_encounter_id, diagnosis_date)
One row per (condition record, matching library concept); concept NULL when no library concept matches. Sources: conditions (EHR problem-list / condition records) and condition_assessments. The EHR `conditions` rows are documented diagnoses: any 'documented' or 'diagnosed' check must include condition rows with source_table='conditions' as well as problem_list_entry (which is built from the separate problem_lists stream and does not contain them). label = received description. condition holds EHR condition records ONLY (no payer claim diagnoses, no encounter diagnoses, no problem-list entries): count documented diagnoses by ICD-10 code from diagnosis_any (all sources), by concept from concept_patient.
