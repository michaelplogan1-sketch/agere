### wellness_visit(record_id, patient_id, encounter_id, visit_type, hcpcs_code, awv, awv_kind, status, coding_status, event_date, available_date, organization_id, source)
One row per wellness_visit_services record: visit_type (medicare_annual_wellness, preventive_review, ...), hcpcs_code, awv = 1 for a Medicare annual wellness visit (G0438 initial / G0439 subsequent, awv_kind), status (count completed), coding_status, event_date, encounter_id. visit.wellness_visit_type / visit.awv mark the encounter. Generic preventive reviews are not AWVs. source = ehr | payer_claim_line: AWVs known only from a payer claim line G0438/G0439 (not within 1 day of an EHR AWV) are rows too, so count AWVs here, not on visit.
