### appointment(appointment_id, patient_id, scheduled_date, booked_date, final_status, ever_no_show, ever_cancelled, ever_rescheduled, kept, organization_id, clinician_id, purpose, versions, lead_time_days, outcome)
One row per appointment_id (appointments arrive as a booked record plus later status records). scheduled_date from the latest version carrying a scheduled_date (a reschedule moves it), else the date of slot_start (population-feed bookings send booked_at + slot_start); booked_date = earliest booked version; lead_time_days = scheduled_date - booked_date, NULL when either is unknown. final_status = latest status received; ever_* flags over all versions; kept = any arrived, attended or fulfilled version. outcome = kept | no_show (never kept) | cancelled (never kept or no-show) | rescheduled | scheduled (still booked) | unassigned (unassigned_requires_review) | unknown. No-show rate = no_show / (kept + no_show), or with cancelled in the denominator - state which.
