### current_record(stream, key_field, business_id, record_id, patient_id, versions, first_available_date, available_date, event_date, payload)
Latest version of each business entity in versioned (snapshot) streams: stream, key_field, business_id, versions, payload of the latest version. Use it for current state (current balance, current claim status). It drops what earlier versions carried: a status-history stream (appointments: booked -> rescheduled -> fulfilled) records a reschedule reason or an interim status on an earlier version, so "ever" / "had to be rescheduled because" questions read record WHERE stream = ... over all versions (count DISTINCT the key).
