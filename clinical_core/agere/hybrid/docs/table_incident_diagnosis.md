### incident_diagnosis(record_id, patient_id, concept, label, icd10, diagnosis_date, diagnosing_encounter_id, encounter_icd10_match, visit_status, problem_list_note_record_id, first_prescription_record_id, available_date)
Diagnoses made at a completed visit (conditions with diagnosis_basis = clinical_encounter): diagnosis_date (onset, else event date), diagnosing_encounter_id, encounter_icd10_match = 1 when that encounter carries the same ICD-10, problem_list_note_record_id (problem_list_update note on that encounter naming the code), first_prescription_record_id (order written at that encounter).
