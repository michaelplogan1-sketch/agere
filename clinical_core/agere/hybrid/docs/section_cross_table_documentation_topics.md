## Cross-table documentation topics
- enrollment_span_quality: enrollment_span.coverage_end is NULL for open spans, including spans a payer sends with the 9999-12-31 sentinel (open_ended = 1; the literal stays in coverage_end_received). A member ID reissued mid-span (member_id_reissued = 1, previous_member_id = the old ID) is the same person: spans, member months and claims stay on one patient_id.
- measurement_quality: measurement.value_text = result received as text; value_censor = > | < | >= | <= when a censored string such as eGFR ">60" or TSH "<0.01" was read as its bound (value/value_canonical hold the bound; treat as "at least"/"at most"); excluded_reason = test_not_performed | specimen_hemolyzed | no_value_reported | cancelled (no value; never a result); result_current = 0 when a later corrected result or an earlier identical interface message supersedes the row (superseded_by_record_id, supersede_reason = corrected | duplicate_interface_message); local_code = interface code; loinc_source = local_code_map when the LOINC came from LOCAL_LAB_CODES. measurement_latest uses current, non-excluded rows only and carries value_censor.
- normalization: measurement.loinc/component/lab_category, condition.is_diagnosis/icd10_category/chapter/chronic/normalized_label, medication.ingredients/therapeutic_category, visit.setting come from the normalization dictionary (each source string mapped once to standard terminology).
- patient_population: patient.data_segment (deep_chart | claims_plus_ehr | claims_only | duplicate_chart; NULL in panel-only releases), patient.line_of_business/payer_id (latest member_month). condition.diagnosis_basis, diagnosing_encounter_id, diagnosis_date (onset, else event date) on conditions records.
- payer_claim_versions: payer_claim.claim_frequency_code (1 original, 7 replacement, 8 void), original_payer_claim_id (on a replacement), superseded_by_payer_claim_id (on the original), version_status = current | superseded_by_replacement | voided | duplicate_submission, duplicate_submission = 1 when any adjudication carries CARC 18 (exact duplicate), counts_in_metrics = 1 only for the current, non-duplicate version: use it for every count, cost, denial and utilization metric. principal_diagnosis/diagnosis_codes are dotted ICD-10-CM (payers that drop the decimal are normalised; *_received keep the literal); rendering_npi NULL when not sent (rendering_npi_missing).
- payer_pharmacy_reversal: payer_pharmacy_claim.transaction_code B2 = reversal (return to stock: filled, never picked up); reversal_of_record_id / reversed_by_record_id pair it with the paid claim it reverses (the claim a reversal or recoupment names in supersedes_record_id, else the same prescription chain within 30 days); counts_as_fill = 1 only for paid, unreversed claims. medication.fill_reversed = 1 on reversed fills (PDC and fill linkage ignore them).
- standards: Standard codes received from the source sit beside the local values (NULL when a release has none): condition.icd10 (+icd10_source), measurement.loinc (+loinc_source = source | dictionary, loinc_dictionary, reference_range, abnormal_flag), medication.rxnorm (+rxnorm_source = source | dictionary_ingredient, rxnorm_ingredient) and medication.ndc, visit.principal_icd10/place_of_service, claim.drg/drg_grouper_version/principal_diagnosis/diagnosis_codes (JSON)/billing_npi/rendering_npi/type_of_bill/cpt/hcpcs/local_charge_code, patient.birth_date/race/ethnicity/preferred_language/interpreter_needed/marital_status/zip/county (FIPS)/state. Source codes win over dictionary mappings; *_source records which was used. meta.standards holds coverage.
