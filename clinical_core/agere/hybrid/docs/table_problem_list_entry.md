### problem_list_entry(patient_id, problem_key, icd10, label, entries, coded_entries, shorthand_entries, first_recorded, last_confirmed, clinical_status, resolved_date, onset_date, last_supporting_evidence, days_since_confirmed, days_since_evidence, acute, stale, recency_weight, record_id)
Problem list per (patient, ICD-10 category; shorthand such as HTN/DM2 mapped): entries (duplicates collapsed), first_recorded, last_confirmed (latest entry date), clinical_status of the latest entry, last_supporting_evidence (latest payer-claim or encounter diagnosis in the category), stale = 1 when neither confirmed nor supported in 365 days (or an acute problem left active > 90 days), recency_weight = 0.5 ^ (days since the later of the two / 365). Down-weight stale entries. Built from the problem_lists stream only: EHR problem-list entries delivered as `conditions` records are in condition (source_table='conditions'), so a documented-diagnosis check must union both.
