# Explicit received-source expansion and packet follow-through

Agere now previews exact typed record references beyond the historical native catalog, lets a user explicitly select the evidence, and binds saved interpretations back to the original question. A second integration links that exact selection and its answer to an authenticated internal packet review. Existing contexts, answers, work events and frozen engines remain unchanged.

## Executable path

Patient/service-fit questions and documentary prerequisites expose **Inspect and expand exact source references**. The preview preserves the original question and roots, source hashes, decision cutoff, typed edges, unresolved references and the difference from the historical scope. It follows same-patient, received, exact references in both directions, rejects oversized components without truncation, and does not infer clinical relationships or guess unmapped references.

Explicit selections retain every original root. The resulting context identifies selected records, excluded reachable records, source omissions and unresolved references. Saved machine answers must match the exact context and patient, be complete and include required reconciliation. Attachment leaves the requirement and current patient confirmation unresolved.

The packet follow-up panel can bind an existing selection to the current recorded packet review using the existing scoped reviewer credentials. Changed source/selection/review/packet dependencies make historical receipts stale. Returned answers are saved against both the packet review and original question. Credentials cannot be supplied as body authority, and no patient action or clinician review is inferred. The two answer stores use an idempotent recoverable sequence, not a claimed cross-database atomic transaction.
