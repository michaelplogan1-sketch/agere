# Dated reference evidence connected to internal review work

Agere now connects a public guideline assertion to an exact existing service question and creates persistent applicability questions under that task's owner. This is an executable reference-to-question-to-evidence workflow, with explicit patient and source dependencies. It does not establish that the recommendation applies or record a clinical review.

The initial source is the [official 2023 ATS pulmonary rehabilitation guideline](https://pmc.ncbi.nlm.nih.gov/articles/PMC10449064/), DOI 10.1164/rccm.202306-1066ST, Question 5. The stored assertion separates source quotation, citation/locator, reported recommendation strength, reported evidence quality, evidence limitations and the Agere mapping's unreviewed status. It has no patient-specific effect estimate, invented independent-study count or clinical qualification. One guideline assertion is connected; this is not a comprehensive literature registry or review.
